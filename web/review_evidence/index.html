001: # GeoFamiliar
002: 
003: **いつもの場所から、生活圏だけの相棒を育てる位置情報ゲーム。**
004: 
005: 駅、公園、カフェ、夜のコンビニなど、通った場所の気配が「生活圏DNA」になり、
006: 相棒の性格、気分、記憶、週間進化を形づくります。
007: 
008: > Status: デモ / プレビュー版です。現在地取得は任意で、取得できた場合だけ場所カテゴリの候補に反映します。座標や住所は保存せず、記憶にはカテゴリ級の場所ヒントだけを残します。天気、アカウント、バックエンド、自由生成AIはまだモックです。
009: > 相棒の見た目は、6フォーム x 4進化段階 x 3ムードの生成PNG資産 v1 を使用しています。
010: 
011: ## 現在地と場所意味化の実装範囲
012: 
013: - 実端末では `geolocator` で現在地許可を求めます。拒否しても手動選択で遊べます。
014: - 現在地が取得できた場合、`PlaceResolver` が OpenStreetMap Nominatim の逆引きを試みます。
015: - 逆引きはタイムアウト・HTTP失敗・オフライン時にローカルfallbackへ戻ります。
016: - 記憶に保存するのは `PlaceContext.displayHint` のようなカテゴリ級ヒントだけです。正確な住所と正確な座標は保存しません。
017: - 実装ファイル:
018:   - `lib/services/location_service.dart`
019:   - `lib/services/place_resolver.dart`
020:   - `lib/models/place_context.dart`
021:   - `lib/models/walk.dart`
022:   - `lib/logic/memory_generator.dart`
023: 
024: ## 静的検収証跡
025: 
026: - アート差分: `web/art_acceptance/`
027: - 場所カテゴリ因果: `web/place_evidence/`
028: - 場所カテゴリ因果シートは、同じ初期条件から `水辺の近く x5` と `商業地の近く x5` で、生活圏DNA・相棒の姿・記憶文が分岐することを示します。
029: 
030: ## コアループ
031: 
032: 1. **誕生** - 今日の場所、時間帯、天気から相棒を生まれさせる。
033: 2. **ホーム** - 相棒の姿、気分、生活圏DNA、今週の進捗を見る。
034: 3. **さんぽ記録** - 歩いたあとに、実際に通った場所を追加する。現在地から候補追加も可能。
035: 4. **記憶** - 記録したさんぽから、相棒の短い日記が生まれる。
036: 5. **進化 / プレミアム** - 一週間のさんぽを進化カードにし、継承やアルバムの価値を見せる。
037: 
038: ## 安全とプライバシー
039: 
040: - 現在地取得は任意。拒否しても手動選択で遊べます。
041: - 現在地はリバースジオコードでカテゴリ推定する場合があります。保存するのは「駅周辺」「水辺の近く」などの広い場所ヒントだけです。
042: - 速度、距離、危ない寄り道、深夜の無理な外出は評価しません。
043: - 記憶文はテンプレート生成で、自由生成AIの過剰表現はしていません。
044:

016:   Future<PlaceContext> resolve(double latitude, double longitude) async {
017:     final coarseLat = _coarse(latitude);
018:     final coarseLon = _coarse(longitude);
019:     final cacheKey = '$coarseLat,$coarseLon';
020:     final cached = _cache[cacheKey];
021:     if (cached != null) return cached;
022: 
023:     final fallback = _fallback(latitude, longitude, coarseLat, coarseLon);
024:     final httpClient = client ?? http.Client();

028:       final uri = Uri.https('nominatim.openstreetmap.org', '/reverse', {
029:         'format': 'jsonv2',
030:         'lat': latitude.toStringAsFixed(6),
031:         'lon': longitude.toStringAsFixed(6),
032:         'zoom': '17',
033:         'addressdetails': '1',
034:       });
035:       final response = await httpClient
036:           .get(uri, headers: {'Accept': 'application/json'})
037:           .timeout(timeout);
038:       if (response.statusCode < 200 || response.statusCode >= 300) {
039:         _cache[cacheKey] = fallback;

041:       }

044:       if (decoded is! Map<String, dynamic>) {
045:         _cache[cacheKey] = fallback;
046:         return fallback;
047:       }
